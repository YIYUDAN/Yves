# 5-shot 交接说明（方案二：背景裁剪 + 支持集微调 + 逻辑回归读出）

本 README 记录 5-shot 任务的完整实现：方案二（背景裁剪 + 支持集微调 + 逻辑回归读出）、与方案一的对比、背景裁剪与消融实验、误分类分析、预训练重训实验以及复现方式。1-shot 部分和原有文件不受影响。

## 结论速览

方案一和方案二统一使用组内共享的 AdamW-150 预训练权重 `outputs/pretrain/best_wrn16_2_adamw150_shared.pth`（base_val 56.33%），输入统一走同一套 GrabCut 背景裁剪，方案二使用 global_max 特征和翻转 TTA：

| 方案 | 正确数 / 总数 | 准确率 | 宏平均 F1 |
| :--- | :------------ | :----- | :-------- |
| 方案一：冻结特征 + 余弦原型 | 160 / 250 | 64.00% | 0.6351 |
| 方案二：支持集微调 + 逻辑回归读出 | 166 / 250 | **66.40%** | **0.6570** |

方案二相对方案一提升 **+2.40 个百分点**，宏 F1 提升 **+0.0219**。

最终选共享 AdamW-150 权重的依据是同一套流程在三份权重上都跑过：

| 权重 | base_val | 方案一 | 方案二 |
| :--- | :------- | :----- | :----- |
| 原始 `best_wrn16_2.pth` | 35.00% | 46.80% | 50.40% |
| 自训重训 `best_wrn16_2_retrained.pth` | 40.33% | 50.80% | 52.00% |
| 组内共享 `best_wrn16_2_adamw150_shared.pth` | **56.33%** | **64.00%** | **66.40%** |

三份权重下共享模型在两个方案上都最好，因此两方案统一用共享权重，保证对比公平。原始权重与自训重训权重的结果分别保留在 `outputs/fewshot/5shot_v2/` 和 `outputs/fewshot/5shot_retrained_v2/`。

## 重要修正说明

早期版本曾报告方案二 58.00%，复现时发现两个问题，现已修正，上面的数字是修正后的结果：

1. **随机种子没有真正生效。** 当时只调用了 `torch.manual_seed`，没有重置 Python `random` 与 numpy 的随机状态，三个种子的数据增强序列实际相同，"三种子集成"退化成同一次运行的三份拷贝，结果偏乐观。现在三个库统一播种，三个种子的损失曲线和准确率都不同。
2. **两方案输入不一致。** 早期方案一不裁剪、方案二裁剪，对比不公平。现在两者共用同一裁剪函数。

## 数据使用边界

- 支持集固定为 `-01.jpg` 到 `-05.jpg`，共 5 类 × 5 张 = 25 张，仅用于适配与拟合读出分类器。
- 查询集共 250 张，只在最终预测和指标计算时读取，没有参与训练、调参或统计量估计。
- 预训练数据只用于预训练，没有和小样本数据混用。
- 特征标准化和逻辑回归都只用支持集统计量拟合。

## 方案二方法

### 动机

方案一完全冻结网络，只提取 GAP 特征并用余弦相似度匹配类原型。问题在于：预训练模型只在 30 个 base 类上学习过，其特征空间对 5 个目标类不一定判别充分；而 5 张支持图片的类原型也容易受背景、视角和光照影响。课上讲的"背景信息形成干扰"在误分类样本里能直接看到：黑足鼬旁边一个大号青绿色塑料盆，就把预测拉到了校车。

方案二做两件事：先把主体从背景里裁出来，再把支持集从"只算原型"改为"用来更新参数"，最后用一个判别式读出替换最近原型分类。思路参考：

- Chen et al., *Meta-Baseline: Exploring Simple Meta-Learning for Few-Shot Learning*, ICCV 2021：在支持集上微调并使用余弦分类器。
- Zhang et al., *Tip-Adapter: Training-free Adaption of CLIP for Few-shot Classification*, ECCV 2022：把支持集特征直接用于轻量适配与读出。

### 流程

1. 对每张图做 GrabCut 背景裁剪，裁出主体后统一送进网络。
2. 加载预训练 WRN-16-2，保留全部卷积层参数。
3. 用 25 张支持图片做强增强：`RandomResizedCrop(224, scale=(0.55, 1.0))`、水平翻转、`ColorJitter(0.4, 0.4, 0.4, 0.1)`、`RandomErasing(p=0.25)`。
4. 全参数微调，同时训练一个随机初始化的余弦分类头（128 维特征、5 类、可学习温度）；损失为带标签平滑 0.1 的交叉熵；优化器 AdamW，学习率 1e-4，权重衰减 1e-4，余弦退火 100 轮；BN 统计量随支持集更新。
5. 用微调后的网络提取支持集和查询集的 128 维 GAP 特征（评估变换为 Resize 256 + CenterCrop 224）。
6. 在支持集特征上做标准化，拟合 L2 正则的多项逻辑回归（`C=1.0`），输出查询集概率。
7. 用 3 个随机种子（2026、1234、777）重复上述过程，对概率取平均作为最终预测。

### 背景裁剪

在 256 短边的缩放图上用 GrabCut 做矩形初始化分割，5 次迭代，取前景掩码的外接方形框并外扩 10%，再裁回原图坐标。

有一个必须加的保护：如果外接框面积不足原图的 50%，就以框中心把方形扩到 50% 再裁。不加这条时实测会锁到局部，例如 `G05-Q-00-31` 只留狗头、`G05-Q-04-03` 只留校车前脸、`G05-Q-03-23` 只留沙漏中段，最极端的 `G05-Q-02-02` 锁到了箱子前面的人头，主体板条箱几乎没进框。

全部 275 张图（25 支持 + 250 查询）的裁剪覆盖率：

| 指标 | 无面积保护 | 有面积保护 |
| :--- | :--------- | :--------- |
| 中位保留面积 | 0.836 | 0.836 |
| 最小保留面积 | 0.120 | 0.495 |
| 保留面积 < 0.4 | 12 张 | 0 张 |

### 与方案一的实质区别

| 维度 | 方案一 | 方案二 |
| :--- | :--- | :--- |
| 可训练参数 | 0，网络和 BN 全部冻结 | WRN 全部参数 + 余弦分类头 + 逻辑回归分类器 |
| 训练目标 | 无训练，余弦相似度匹配类原型 | 支持集交叉熵（标签平滑）+ 逻辑回归的 L2 正则交叉熵 |
| 样本利用方式 | 每类 5 张原图各用一次，直接求均值原型 | 25 张图经 100 轮强增强重复使用，共 2500 个增强样本，再叠加 3 个种子 |

最核心的区别是"支持集参与参数更新"。

### 关键参数

| 参数 | 取值 |
| :--- | :--- |
| 支持集 | 每类 `-01.jpg` 至 `-05.jpg` |
| 背景裁剪 | GrabCut，5 次迭代，外扩 10%，面积下限 50% |
| 输入尺寸 | 224 × 224 |
| 微调轮数 | 100 |
| 学习率 | 1e-4，余弦退火 |
| 优化器 | AdamW，weight decay 1e-4 |
| 标签平滑 | 0.1 |
| 余弦头初始化 | 随机 |
| 读出分类器 | 逻辑回归，`C=1.0`，支持集标准化 |
| 特征模式 | `global_max`（GAP 拼接最大池化，256 维） |
| 测试增强 | 水平翻转 TTA（原图与翻转图特征取平均） |
| 集成种子 | 2026、1234、777 |

## 消融实验

原始权重、单种子 2026、`C=1.0`，只改一项目：

| 配置 | 准确率 |
| :--- | :----- |
| 不裁剪 + 原型初始化余弦头 | 45.60% |
| 不裁剪 + 随机初始化余弦头 | 49.20% |
| GrabCut（无面积保护）+ 原型初始化 | 44.40% |
| GrabCut（有面积保护）+ 随机初始化 | **50.00%** |
| GrabCut（有面积保护）+ 3 种子集成 | 50.40% |

结论：

- **原型初始化余弦头是负收益**，同条件下掉了约 3.6 个百分点，已改为随机初始化。直觉上把支持集原型塞进分类头很合理，但支持集特征受背景影响，这个初值本身有偏，100 轮微调后反而把网络带偏。
- **面积保护是必要的**，没有保护时 GrabCut 会锁到局部，准确率比不裁剪还低。
- 种子确实会改变结果，单种子在 48.0% 到 52.8% 之间波动，所以必须报集成结果而不是挑最高的一次。

## 复现方式

在仓库根目录、`python_course` 环境下执行（本次运行环境为 torch 2.8.0+cu126、RTX 3060 Laptop、6GB 显存）：

```bash
python -m src.fewshot.eval_baseline --k 5 --crop-mode grabcut --weights outputs/pretrain/best_wrn16_2_adamw150_shared.pth --out outputs/fewshot/5shot_adamw150
python -m src.fewshot.adapt --crop-mode grabcut --head-init random --c-value 1.0 --seeds 2026,1234,777 --feature-modes global_max --tta --weights outputs/pretrain/best_wrn16_2_adamw150_shared.pth --out outputs/fewshot/5shot_adamw150
```

重训预训练模型：

```bash
python -m src.train_pretrain_retrained
```

`adapt.py` 支持的主要参数：

| 参数 | 说明 |
| :--- | :--- |
| `--weights` | 预训练权重路径 |
| `--crop-mode` | `none`、`center`、`grabcut` |
| `--crop-modes` | 交叉验证时比较的裁剪模式列表 |
| `--head-init` | `random`、`prototype` |
| `--seeds` | 逗号分隔的种子列表 |
| `--epochs` | 微调轮数 |
| `--lr` | 学习率 |
| `--c-value` | 逻辑回归的 C |
| `--c-values` | 交叉验证时比较的 C 列表 |
| `--out` | 输出目录 |

### 逐种子结果（共享 AdamW-150 权重）

| 种子 | 正确数 / 总数 | 准确率 |
| :--- | :------------ | :----- |
| 2026 | 168 / 250 | 67.20% |
| 1234 | 170 / 250 | 68.00% |
| 777 | 166 / 250 | 66.40% |
| 三种子概率平均 | 166 / 250 | 66.40% |

三个种子波动较小（66.4% 到 68.0%），集成结果与最差种子持平、略低于最好的单种子。这里概率平均没有拉高准确率，原因是三个种子预测方向高度一致，平均后高置信度被拉平，但概率平均仍然降低了单种子挑选带来的报告偏差，所以最终报集成结果。

### 误分类样本分析

完整列表在 `outputs/fewshot/5shot_adamw150/misclassified_samples.csv`，按真实类概率升序排列；可视化在前 6 张的 `misclassified_grid.png`。

![误分类示例](outputs/fewshot/5shot_adamw150/misclassified_grid.png)

**1. `G05-Q-02-49.jpg`：板条箱 → 非洲野犬，p(pred)≈0.77**

图像是黄绿色木箱的极近特写，只看到箱角、金属合页和侧面文字，没有完整箱体。支持集的板条箱是完整物体、常规视角，查询图在尺度、构图和局部纹理上都偏离。背景裁剪在这里没帮上忙，因为整张图都是箱子，GrabCut 裁不出"更整的箱子"。

**2. `G05-Q-03-12.jpg`：沙漏 → 非洲野犬，p(pred)≈0.77**

查询图是一幅带文字的古典版画，沙漏以线描和排线形式出现，而支持集和预训练数据基本都是照片。线描图像的边缘、纹理和色彩统计与照片差异很大，属于明显的域偏移，属于 cross-domain 能力的短板。

**3. `G05-Q-01-04.jpg`：黑足鼬 → 校车，p(pred)≈0.67**

画面左侧是主体黑足鼬，右侧和中央被一个高饱和度的青绿色塑料盆占据。加入背景裁剪后概率从接近 1.00 降到 0.67，说明裁剪确实削弱了干扰物，但没有完全纠正：GrabCut 把人和盆一起当成了前景，主体仍不是画面里面积最大的东西。这条说明单次 GrabCut 不足以处理"干扰物和主体粘连"的情况。

## 预训练重训实验

原预训练配置：30 轮、batch 8、SGD 学习率 0.01、简单裁剪翻转增强，`base_val` 最好 35.00%（第 27 轮），训练约 1608 秒。

重训改动：

| 项目 | 原配置 | 重训配置 |
| :--- | :--- | :--- |
| 轮数 | 30 | 60 |
| batch size | 8 | 24 |
| 学习率 | 0.01 | 0.02，5 轮 warmup 后余弦退火 |
| 权重衰减 | 原有设置 | 5e-4 |
| 标签平滑 | 无 | 0.1 |
| 增强 | 裁剪 + 翻转 | RRC(0.4-1.0) + 翻转 + ColorJitter + RandomErasing(0.2) |
| 数据读取 | 每轮读盘 | 预先缩放到 256 × 256 缓存在内存 |
| 最好 base_val | 35.00% | **40.33%（第 54 轮）** |

重训权重与日志：

- `outputs/pretrain/best_wrn16_2_retrained.pth`
- `outputs/pretrain/last_wrn16_2_retrained.pth`
- `outputs/pretrain/train_log_retrained.csv`
- `outputs/pretrain/loss_curve_retrained.png`
- `outputs/pretrain/acc_curve_retrained.png`
- `outputs/pretrain/config_used_retrained.json`

结论：

- 重训把 base_val 从 35.00% 提到 40.33%，在两份 5-shot 流程上也都更好（方案一 46.80% → 50.80%，方案二 50.40% → 52.00%）。
- 同组共享的 AdamW-150 权重 base_val 达 56.33%，在同样的 5-shot 流程上方案一 64.00%、方案二 66.40%，是三者中最好的，因此最终采用共享权重。
- 重训和共享权重都只用了 base_train 更新参数、base_val 选模型，没有加载任何外部预训练权重，也没有碰支持集和查询集。

## 局限与可继续尝试的方向

- 单种子在 66.4% 到 68.0% 之间波动，集成后 66.4%。可以尝试只微调 layer3、冻结 BN，或加 EMA 来进一步压方差。
- 黑足鼬召回率从方案一的 42 掉到方案二的 30，主要被误判为非洲野犬。全参数微调在 25 张图上会把相邻类的边界拉偏，可尝试只微调高层或加类间正则。
- GrabCut 对"干扰物与主体粘连"的图像无效，可以尝试检测框或显著性先验；也可以只在支持集与查询集都裁得干净时才启用裁剪。
- 板条箱近景/版画样本仍难分，可尝试多尺度特征或注意力池化。
- 逻辑回归只在 25 个支持特征上拟合，容量有限；可尝试在微调过程中联合训练线性分类头，但要小心过拟合。
